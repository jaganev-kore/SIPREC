WHAT SIPREC DOES

It sends call audio to Kore for Agent Assist.

A SIPREC Session Recording Client (SRC) on the call’s media path sends the recording session, audio streams, and metadata to Kore. After a supported stream reaches the service, the transcript is available in Kore.ai Agent Assist.

iThe live test above sends one browser microphone stream through this VM as a SIPREC session. It does not display the transcript; view that in Kore.ai.
